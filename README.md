# Portfolio Monorepo

Этот репозиторий содержит стартовый каркас персонального сайта-портфолио, собранный по вертикально-модульной архитектуре из `rules/portfolio_architecture_plan_v4.md`.

## Что уже заложено

- монорепозиторий с `apps/`, `packages/`, `modules/`, `backend/`, `tools/`;
- общие типы, контракты, ошибки и дизайн-токены;
- каркас публичного frontend и административной панели на React + TypeScript + SCSS;
- backend-скелет на FastAPI-архитектуре с разделением на API, application, domain и infrastructure;
- контентный формат `portfolio.v1` и стартовые демонстрационные данные;
- инфраструктурные шаблоны для Docker Compose, Nginx и CI.

## Ограничения текущей машины

- в среде доступен `node` и `npm`;
- `pnpm`, `uv` и Python-рантайм в `PATH` пока отсутствуют;
- поэтому lock-файлы и реальный запуск backend не были сгенерированы автоматически в этом проходе.

## Ближайшие шаги

1. Установить frontend-зависимости и проверить сборку `apps/web` и `apps/admin`.
2. Подключить Python 3.13 + `uv` и поднять backend-модуль `projects` как первый эталонный vertical slice.
3. Завести автоматический импорт резюме через `tools/cv-importer/`.
4. Перенести демо-контент в PostgreSQL и Redis, оставив YAML/JSON как экспортируемый формат.
