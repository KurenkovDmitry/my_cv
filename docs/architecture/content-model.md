# Модель контента `portfolio.v1`

`portfolio.v1` используется как переносимый формат, который можно:

- импортировать в backend;
- экспортировать из административной панели;
- валидировать в CI;
- хранить как черновик до публикации.

## Принципы

- формат не содержит секретов;
- каждая локализуемая строка хранится как объект `ru` / `en`;
- спорные данные помечаются через `needsManualReview` или `status: needs_review`;
- изображения описываются ссылками на ассеты, а не бинарными данными;
- формат может быть преобразован в PostgreSQL-модель, но не зависит от неё.

## Минимальные разделы

- `profile`;
- `projects`;
- `themes`;
- `localization`;
- `accessibility`;
- `seo`.
