# CV Importer

Инструмент предназначен для безопасного извлечения данных из резюме и подготовки черновика `portfolio.v1`.

## Цели

- принять PDF, DOCX, ODT, TXT, Markdown, HTML и изображения;
- извлечь текст;
- распознать разделы резюме;
- сформировать `portfolio.import.draft.yaml`;
- сформировать `portfolio.import.report.json`;
- пометить неоднозначные поля как требующие ручной валидации.

## Ограничения текущего каркаса

- Python-рантайм в среде ещё не подключён;
- поэтому реализован только структурный шаблон и документация;
- реальный PDF parser и OCR-адаптер нужно добавить после установки `uv`.
